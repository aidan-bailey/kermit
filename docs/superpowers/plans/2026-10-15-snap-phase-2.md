# SNAP Phase 2 (#96): the SNAP Generator Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `kind: snap` benchmarks. A spec names a SNAP community graph (or gives a URL and its SHA-256). Generation downloads the `.gz`, symmetrises it into one `edge(src, dst)` relation, writes it through the `kermit-generate` layer, and emits the triangle, path3, cycle4 and clique4 queries, each with an exact `expected` count from an oracle that shares no code with the joins. `benchmarks/snap-amazon.yml` and `snap-dblp.yml` are committed, and `bench gen snap` generates any graph on demand.

**Architecture:**
- **Spec types (T1, T5).** `SnapGraph` and `SnapQuery` are kermit-bench types, so discovery reads them. T1 adds the types alone. T5 adds `GeneratorSpec::Snap`, its validation and the binary's `materialize` dispatch arm in one commit, because `dispatch` matches exhaustively.
- **The generator (T2–T4)** lives in `kermit-generate/src/snap.rs` and `snap/counts.rs`, on H2O's layer (`Generator`, `RelationSink`, `run`):
  - the parser: `.gz` → cleaned, symmetrised `Tuples`, with edgeless input rejected;
  - the oracle: a CSR plus degree orientation, checked `u64`;
  - the generator: download through phase 1's `download_verified`, parse, write, count.
- **The CLI (T6, T7).**
  - T6 makes `materialize` keep an `anyhow` context chain (`{e:#}`), its own commit, first lander only.
  - T7 adds `bench gen snap` on the shared `GenTarget`, copied verbatim from H2O's spec, first lander only.
- **Tests and data (T8):** the committed YAMLs, a mini fixture, an end-to-end test over every cell × optimiser × column-order policy, and the CLI tests (`--url`, a wrong digest, the declarative miss → hit → drift → `--force` path).
- **Docs (T9)** and **the gate (T10).**
- **Untouched:** the join engine, the data structures, kermit-rdf, and H2O's layer.

**Tech Stack:** Rust nightly (workspace `rust-toolchain.toml`, edition 2021: no let-chains), the nix dev shell for every cargo command and for rustfmt, `flate2` 1 (new in kermit-generate), clap 4 `ValueEnum`, `arrow`/`parquet` 59.3 (dev-dependencies of kermit), and a loopback HTTP server in tests.

**Spec:** `docs/specs/2026-10-15-snap-benchmark-design.md` (approved; phase-2 decisions in ab124ec and 9dab8b6). **Names contract:** `docs/superpowers/plans/2026-10-15-snap-phase-2-contract.md`; it is binding, and its § Updates records H2O push 1b's stricter `run`.     /// `com-amazon`: the Amazon product co-purchasing network.
```rust
    ComAmazon,
    /// `com-dblp`: the DBLP collaboration network.
    ComDblp,
    /// `com-youtube`: the YouTube social network.
```

```rust
//! SNAP community graphs (Yang & Leskovec, ICDM 2012) as a benchmark.
//!
//! [`parse_edge_list`] and [`parse_gz`] turn a SNAP edge list into the one
//! symmetric `edge(src, dst)` relation every SNAP benchmark has. Comments are
//! skipped; a self-loop and a repeat of an unordered pair are dropped and
//! counted; each kept line `s d` contributes the rows `(s, d)` and `(d, s)`,
//! with the raw ids. A malformed line is an error that names where it is
//! (#78), never a skipped line.

mod counts;

#[cfg(test)]
mod tests {
    use {
        super::*,
        flate2::{write::GzEncoder, Compression},
        std::{fs, io::Write},
    };

    fn parse(text: &str) -> anyhow::Result<ParsedEdges> {
        parse_edge_list(text.as_bytes(), "t.txt")
    }

    fn gzip(text: &str) -> Vec<u8> {
        let mut encoder = GzEncoder::new(Vec::new(), Compression::default());
        encoder.write_all(text.as_bytes()).unwrap();
        encoder.finish().unwrap()
    }

    #[test]
    fn edge_header_names_the_relation() {
        let header = edge_header();
        assert_eq!(header.name(), "edge");
        assert_eq!(header.attrs(), ["src", "dst"]);
        assert_eq!(header.arity(), 2);
    }

    #[test]
    fn comments_are_skipped() {
        let parsed = parse("# a header\n# Nodes: 3\n1\t2\n# in the middle\n2 3\n").unwrap();
        assert_eq!(parsed.input_edges, 2);
        assert_eq!((parsed.self_loops, parsed.duplicates), (0, 0));
        assert_eq!(parsed.tuples.to_vecs(), vec![
            vec![1, 2],
            vec![2, 1],
            vec![2, 3],
            vec![3, 2]
        ]);
    }

    #[test]
    fn a_malformed_line_names_its_number_and_text() {
        let cases: [(&str, usize, &str); 9] = [
            ("1\n", 1, "1"),
            ("# c\n1 2\n1 2 3\n", 3, "1 2 3"),
            ("a b\n", 1, "a b"),
            ("1 -2\n", 1, "1 -2"),
```

```rust
/// A parsed, cleaned and symmetrised SNAP edge list.
#[derive(Debug)]
pub struct ParsedEdges {
    /// Arity 2: each kept line's (s, d) then (d, s), in file order.
    pub tuples: Tuples,
    /// Data lines read (comments excluded).
    pub input_edges: u64,
    /// Lines with s == d, dropped.
    pub self_loops: u64,
    /// Lines whose unordered pair had appeared before, dropped (a reversed
    /// repeat included).
    pub duplicates: u64,
}

/// Parses a SNAP edge list. `source` names the input in errors (a path or
/// URL).
///
/// A line starting with `#` is a comment. Any other line must be exactly two
/// whitespace-separated unsigned integers; a self-loop (s == d) and a repeat
/// of an unordered pair are dropped and counted, and each kept line pushes
/// (s, d) then (d, s).
///
/// # Errors
///
/// A line that is not a comment and not two unsigned integers (a blank line
/// included) is an error naming its 1-based line number, comments counted,
/// and its text. So is a list with no line left after cleaning, and an
/// unreadable input.
pub fn parse_edge_list(reader: impl BufRead, source: &str) -> anyhow::Result<ParsedEdges> {
    let mut tuples = Tuples::new(2);
    let mut seen: HashSet<(usize, usize)> = HashSet::new();
    let (mut input_edges, mut self_loops, mut duplicates) = (0u64, 0u64, 0u64);
    for (index, line) in reader.lines().enumerate() {
        let number = index + 1;
        let line = line.with_context(|| format!("{source}:{number}: unreadable line"))?;
        if line.starts_with('#') {
            continue;
        }
        let Some((s, d)) = parse_edge_line(&line) else {
            bail!(
                "{source}:{number}: malformed edge line {line:?}: expected two unsigned \
                 integers"
            );
        };
        input_edges += 1;
        if s == d {
            self_loops += 1;
        } else if !seen.insert((s.min(d), s.max(d))) {
            duplicates += 1;
        } else if tuples.len() + 2 > kermit_ds::RowId::MAX as usize {
            // `Tuples::push` panics past `RowId::MAX` rows; a `--url` graph
            // can be that large, so report it instead.
            bail!(
                "{source}:{number}: more edges than one `Tuples` batch holds ({} rows)",
                kermit_ds::RowId::MAX
            );
        } else {
            tuples.push(&[s, d]);
            tuples.push(&[d, s]);
        }
    }
    if tuples.is_empty() {
        bail!(
            "{source} has no edges after dropping {self_loops} self-loops and {duplicates} \
             duplicates"
        );
    }
    tuples.shrink_to_fit();
    Ok(ParsedEdges {
        tuples,
        input_edges,
        self_loops,
        duplicates,
    })
}

/// The two ids on a data line, or `None` unless it is exactly two
/// whitespace-separated unsigned integers.
fn parse_edge_line(line: &str) -> Option<(usize, usize)> {
    let mut fields = line.split_whitespace();
    let (Some(s), Some(d), None) = (fields.next(), fields.next(), fields.next()) else {
        return None;
    };
    Some((parse_id(s)?, parse_id(d)?))
}

/// An unsigned decimal integer that fits `usize`. `str::parse` would also
/// accept a leading `+`, which SNAP files never contain.
fn parse_id(field: &str) -> Option<usize> {
    if field.bytes().all(|b| b.is_ascii_digit()) {
        field.parse().ok()
    } else {
        None
    }
}

/// [`parse_edge_list`] over a gzipped file (`flate2::read::MultiGzDecoder`,
/// so a file of several gzip members is read whole). Errors name `path`.
pub fn parse_gz(path: &Path) -> anyhow::Result<ParsedEdges> {
    let file = File::open(path).with_context(|| format!("opening {}", path.display()))?;
    parse_edge_list(
        BufReader::new(MultiGzDecoder::new(file)),
        &path.display().to_string(),
    )
}

/// The text after the last `/` of `url`; all of `url` if it has none.
fn last_segment(url: &str) -> &str { url.rsplit('/').next().unwrap_or(url) }

/// The benchmark-name stem of a URL: its last path segment up to the first `.`
/// (`…/com-orkut.ungraph.txt.gz` gives `com-orkut`). `None` if that is empty.
pub fn url_stem(url: &str) -> Option<&str> {
    let stem = last_segment(url).split('.').next()?;
    (!stem.is_empty()).then_some(stem)
}
```

```rust
//! The count oracle: the exact answer count of each SNAP query, computed from
//! the parsed edge list alone.
//!
//! `--verify` compares a join's count against the `expected` this module
//! produces, so it must be right in ways the joins cannot be wrong. It reads
//! only the parser's `Tuples` and shares no code with `kermit-algos` or with
//! any of `kermit-ds`'s tries: a bug in a seek, an intersection or a descent
//! cannot also be in the number it is checked against.
//!
//! The graph is a CSR (compressed sparse row) adjacency, sized by the largest
//! vertex id plus one, since ids are sparse. With `A` the adjacency matrix and
//! `d(v)` the degree of `v`, the counts are:
//!
//! | query | count | computed as |
//! |---|---|---|
//! | `path3` | `1ᵀA³1` | `Σ d(b)·d(c)` over rows `(b, c)` |
//! | `triangle` | `6 × triangles` | oriented sorted intersections |
//! | `cycle4` | `tr(A⁴)` | `Σ_v Σ_w (A²)_vw²` from a reusable tally |
//! | `clique4` | `24 × 4-cliques` | oriented sorted intersections, twice |
//!
//! Arithmetic is checked `u64`. An overflow is an error: a wrong `expected`
//! is worse than none.

use {
    anyhow::{bail, ensure},
    kermit_bench::SnapQuery,
    kermit_ds::Tuples,
    std::cmp::Ordering,
};

/// The exact answer count of each query in `queries` (same order) over
/// `edges`, a symmetric, self-loop-free, duplicate-free arity-2 batch (what
/// `parse_edge_list` produces). It shares no code with the joins.
///
/// # Errors
///
/// Fails if `edges` is not arity 2, or if a count overflows `u64`.
pub fn expected_counts(edges: &Tuples, queries: &[SnapQuery]) -> anyhow::Result<Vec<u64>> {
    ensure!(
        edges.arity() == 2,
        "the edge batch has arity {}, expected 2",
        edges.arity()
    );
    let graph = Graph::from_rows(edges);
    let mut counts = Vec::with_capacity(queries.len());
    for &query in queries {
        let count = match query {
            | SnapQuery::Triangle => triangle(&graph),
            | SnapQuery::Path3 => path3(&graph),
            | SnapQuery::Cycle4 => cycle4(&graph),
            | SnapQuery::Clique4 => clique4(&graph),
        };
        let Some(count) = count else {
            bail!("the {} count overflows u64", query.name());
        };
        counts.push(count);
    }
    Ok(counts)
}

/// A graph as a CSR adjacency: the neighbours of `v`, sorted, are
/// `neighbours[offsets[v]..offsets[v + 1]]`.
struct Graph {
    /// `vertices + 1` offsets into `neighbours`.
    offsets: Vec<usize>,
    /// Every adjacency list, one after another, each sorted ascending.
    neighbours: Vec<usize>,
}

impl Graph {
    /// Builds the graph whose adjacency lists are the rows' second values
    /// grouped by their first: count degrees, prefix-sum them into offsets,
    /// fill, then sort each list. The input holds both directions of every
    /// edge, so each list is complete.
    fn from_rows(edges: &Tuples) -> Self {
        let vertices = edges.rows().map(|row| row[0].max(row[1]) + 1).max().unwrap_or(0);

        let mut degrees = vec![0usize; vertices];
        for row in edges.rows() {
            degrees[row[0]] += 1;
        }
        let mut offsets = Vec::with_capacity(vertices + 1);
        let mut running = 0;
        offsets.push(running);
        for degree in &degrees {
            running += degree;
            offsets.push(running);
        }

        let mut next = offsets[..vertices].to_vec();
        let mut neighbours = vec![0usize; edges.len()];
        for row in edges.rows() {
            neighbours[next[row[0]]] = row[1];
            next[row[0]] += 1;
        }
        for list in offsets.windows(2) {
            neighbours[list[0]..list[1]].sort_unstable();
        }
        Graph {
            offsets,
            neighbours,
        }
    }

    /// The number of vertices: the largest id plus one.
    fn vertices(&self) -> usize { self.offsets.len() - 1 }

    /// `d(v)`.
    fn degree(&self, v: usize) -> usize { self.offsets[v + 1] - self.offsets[v] }

    /// The sorted neighbours of `v`.
    fn neighbours_of(&self, v: usize) -> &[usize] {
        &self.neighbours[self.offsets[v]..self.offsets[v + 1]]
    }

    /// Whether the edge `u - v` points from `u` to `v` in the degree
    /// orientation: `u → v` iff `(d(u), u) < (d(v), v)`, a total order on the
    /// vertices. Each triangle and each 4-clique has exactly one ordering
    /// consistent with it, so counting along oriented edges counts each once.
    fn precedes(&self, u: usize, v: usize) -> bool {
        (self.degree(u), u) < (self.degree(v), v)
    }

    /// The oriented graph: `N⁺(u)` is the neighbours `v` of `u` with
    /// `u → v`. Filtering keeps each list sorted, and orienting towards the
    /// higher degree keeps `|N⁺(v)|` within `O(√m)`.
    fn oriented(&self) -> Graph {
        let mut offsets = Vec::with_capacity(self.offsets.len());
        let mut neighbours = Vec::new();
        offsets.push(0);
        for u in 0..self.vertices() {
            neighbours.extend(
                self.neighbours_of(u)
                    .iter()
                    .copied()
                    .filter(|&v| self.precedes(u, v)),
            );
            offsets.push(neighbours.len());
        }
        Graph {
            offsets,
            neighbours,
        }
    }
}

/// Calls `found` on each value in both sorted slices, ascending: a merge,
/// `O(|a| + |b|)`.
fn for_each_common(a: &[usize], b: &[usize], mut found: impl FnMut(usize)) {
    let (mut i, mut j) = (0, 0);
    while i < a.len() && j < b.len() {
        match a[i].cmp(&b[j]) {
            | Ordering::Less => i += 1,
            | Ordering::Greater => j += 1,
            | Ordering::Equal => {
                found(a[i]);
                i += 1;
                j += 1;
            },
        }
    }
}

/// `|a ∩ b|` for sorted slices.
fn intersection_size(a: &[usize], b: &[usize]) -> usize {
    let mut size = 0;
    for_each_common(a, b, |_| size += 1);
    size
}

/// 3-step walks, `1ᵀA³1 = Σ_{(b,c)} d(b) · d(c)` over the rows `(b, c)`: a
/// walk `A - B - C - D` is a row `(b, c)` for its middle step, any of the
/// `d(b)` neighbours of `b` for `A` and any of the `d(c)` neighbours of `c`
/// for `D`. Vertices may repeat.
fn path3(graph: &Graph) -> Option<u64> {
    let mut total: u64 = 0;
    for b in 0..graph.vertices() {
        let d_b = graph.degree(b) as u64;
        for &c in graph.neighbours_of(b) {
            let walks = d_b.checked_mul(graph.degree(c) as u64)?;
            total = total.checked_add(walks)?;
        }
    }
    Some(total)
}

/// `6 × Σ_{u → v} |N⁺(u) ∩ N⁺(v)|`: a triangle `a → b → c` (with `a → c`)
/// is found once, at the oriented edge `(a, b)` as the common out-neighbour
/// `c`. The 6 is its orderings as the answers `(A, B, C)` of the rule.
fn triangle(graph: &Graph) -> Option<u64> {
    let out = graph.oriented();
    let mut closed: u64 = 0;
    for u in 0..out.vertices() {
        let out_u = out.neighbours_of(u);
        for &v in out_u {
            let common = intersection_size(out_u, out.neighbours_of(v));
            closed = closed.checked_add(common as u64)?;
        }
    }
    closed.checked_mul(6)
}

/// Closed 4-step walks, `tr(A⁴) = Σ_v Σ_w (A²)_vw²`, not `8 ×` the
/// 4-cycles: walks that double back (`A = C` or `B = D`) count too.
///
/// `(A²)_vw` is the number of 2-step walks `v → u → w`. For each `v` the
/// tally adds 1 at `w` for every such walk, the squares of the touched
/// entries are summed, and only those entries are reset. So `A²` is never
/// formed, and the work is `Σ_u d(u)²`.
fn cycle4(graph: &Graph) -> Option<u64> {
    let mut tally = vec![0u64; graph.vertices()];
    let mut touched: Vec<usize> = Vec::new();
    let mut total: u64 = 0;
    for v in 0..graph.vertices() {
        for &u in graph.neighbours_of(v) {
            for &w in graph.neighbours_of(u) {
                if tally[w] == 0 {
                    touched.push(w);
                }
                tally[w] += 1;
            }
        }
        for w in touched.drain(..) {
            let walks = tally[w];
            tally[w] = 0;
            total = total.checked_add(walks.checked_mul(walks)?)?;
        }
    }
    Some(total)
}

/// `24 × Σ_{u → v} Σ_{w ∈ W} |N⁺(w) ∩ W|` with `W = N⁺(u) ∩ N⁺(v)`: a
/// 4-clique `a → b → c → d` is found once, at the oriented edge `(a, b)`, with
/// `c ∈ W` and `d ∈ N⁺(c) ∩ W`. The 24 is its orderings as the answers
/// `(A, B, C, D)` of the rule.
fn clique4(graph: &Graph) -> Option<u64> {
    let out = graph.oriented();
    let mut common: Vec<usize> = Vec::new();
    let mut found: u64 = 0;
    for u in 0..out.vertices() {
        let out_u = out.neighbours_of(u);
        for &v in out_u {
            common.clear();
            for_each_common(out_u, out.neighbours_of(v), |w| common.push(w));
            for &w in &common {
                let fourth = intersection_size(out.neighbours_of(w), &common);
                found = found.checked_add(fourth as u64)?;
            }
        }
    }
    found.checked_mul(24)
}
```

```rust
    /// Serves `body` as `200 OK` to every connection on a loopback port and
    /// returns the URL of `file` there.
    fn serve(body: Vec<u8>, file: &str) -> String {
        use std::{io::Read, net::TcpListener};

        let listener = TcpListener::bind("127.0.0.1:0").unwrap();
        let url = format!("http://{}/{file}", listener.local_addr().unwrap());
        std::thread::spawn(move || {
            for stream in listener.incoming() {
                let Ok(mut stream) = stream else { return };
                let mut request = Vec::new();
                let mut buf = [0u8; 1024];
                while !request.windows(4).any(|w| w == b"\r\n\r\n") {
                    match stream.read(&mut buf) {
                        | Ok(0) | Err(_) => break,
                        | Ok(n) => request.extend_from_slice(&buf[..n]),
                    }
                }
                let head = format!(
                    "HTTP/1.1 200 OK\r\nContent-Length: {}\r\nConnection: close\r\n\r\n",
                    body.len()
                );
                let _ = stream
                    .write_all(head.as_bytes())
                    .and_then(|()| stream.write_all(&body));
            }
        });
        url
    }
```

```rust
/// The Datalog rule for `query` (the spec's § Workload, verbatim).
///
/// `cycle4` closes with `edge(A, D)`, not `edge(D, A)`: the stored column
/// order rejects the latter with `CyclicAttributeOrder`, and on a symmetric
/// relation the two hold the same tuples.
pub fn rule(query: SnapQuery) -> &'static str {
    match query {
        | SnapQuery::Triangle => "T(A, B, C) :- edge(A, B), edge(B, C), edge(A, C).",
        | SnapQuery::Path3 => "P(A, B, C, D) :- edge(A, B), edge(B, C), edge(C, D).",
        | SnapQuery::Cycle4 => "C(A, B, C, D) :- edge(A, B), edge(B, C), edge(C, D), edge(A, D).",
        | SnapQuery::Clique4 => {
            "K(A, B, C, D) :- edge(A, B), edge(A, C), edge(A, D), edge(B, C), edge(B, D), \
             edge(C, D)."
        },
    }
}

/// Where a graph's `.gz` comes from.

pub enum SnapSource {
    /// A local `.gz` (tests).
    Local(PathBuf),
    /// A URL and its pinned SHA-256, fetched with
    /// `kermit_bench::cache::download_verified`.

    pub fn named(graph: SnapGraph) -> Self {

/// SNAP's own `meta.json` fields, flattened beside the common ones.
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct SnapExtras {
    /// The named graph, or `None` for a URL or a local file.
    pub graph: Option<SnapGraph>,
    /// The URL the `.gz` came from; `None` for a local source.
    pub source_url: Option<String>,

    pub gz_sha256: String,
    /// Data lines read (comments excluded).
    pub input_edges: u64,
    /// Lines with the same source and destination, dropped.
    pub dropped_self_loops: u64,
    /// Lines repeating an unordered pair seen before, dropped.
    pub dropped_duplicates: u64,
}

/// Generates a SNAP benchmark: one symmetric `edge` relation and up to four
/// queries, each with the exact count the oracle computed.
#[derive(Debug)]
pub struct SnapGenerator<'a> {
    target: Target<'a>,
    /// `Some` for a named graph, recorded in `meta.json`.
    graph: Option<SnapGraph>,
    source: SnapSource,
    /// Already defaulted to all four when the caller gave none.
    queries: Vec<SnapQuery>,
}

impl<'a> SnapGenerator<'a> {
    /// `queries: None` means [`SnapQuery::ALL`].
    pub fn new(
        target: Target<'a>, graph: Option<SnapGraph>, source: SnapSource,
        queries: Option<&[SnapQuery]>,
    ) -> Self {
        Self {
            target,
            graph,
            source,
            queries: queries.map_or_else(|| SnapQuery::ALL.to_vec(), <[SnapQuery]>::to_vec),
        }
    }

    /// What the benchmark's description calls the graph: its name, else the
    /// stem of its URL or file name.
    fn label(&self) -> &str {
        if let Some(graph) = self.graph {
            return graph.name();
        }
        let stem = match &self.source {
            | SnapSource::Local(path) => path.to_str().and_then(url_stem),
            | SnapSource::Remote { url, .. } => url_stem(url),
        };
        stem.unwrap_or("edge list")
    }
}

impl Generator for SnapGenerator<'_> {
    type Extras = SnapExtras;

    const KIND: &'static str = "snap";

    fn target(&self) -> Target<'_> { self.target }

    fn generate(&self, sink: &mut RelationSink) -> anyhow::Result<Generated<SnapExtras>> {
        let raw = sink.raw_dir()?;
        let (gz, source_url) = match &self.source {
            | SnapSource::Local(path) => {
                let Some(name) = path.file_name() else {
                    bail!("{} has no file name", path.display());
                };
                let dest = raw.join(name);
                fs::copy(path, &dest).with_context(|| {
                    format!("copying {} to {}", path.display(), dest.display())
                })?;
                (dest, None)
            },
            | SnapSource::Remote { url, sha256 } => {
                let name = last_segment(url);
                if matches!(name, "" | "." | "..") {
                    bail!("{url} does not end in a file name");
                }
                let dest = raw.join(name);
                download_verified(url, &dest, sha256)
                    .with_context(|| format!("downloading {url}"))?;
                (dest, Some(url.clone()))
            },
        };
        let gz_sha256 = sha256_hex(&gz)?;

        let parsed = parse_gz(&gz)?;
        sink.write(&edge_header(), &parsed.tuples)?;

        let counts = expected_counts(&parsed.tuples, &self.queries)?;
        let queries = self
            .queries
            .iter()
            .zip(counts)
            .map(|(&query, count)| QueryDefinition {
                name: query.name().to_string(),
                description: query_description(query).to_string(),
                query: rule(query).to_string(),
                expected: Some(count),
            })
            .collect();

        Ok(Generated {
            description: format!(
                "SNAP {}: one symmetric `edge` relation; queries count walks, not simple paths or cycles",
                self.label()
            ),
            queries,
            extras: SnapExtras {
                graph: self.graph,
                source_url,
                gz_sha256,
                input_edges: parsed.input_edges,
                dropped_self_loops: parsed.self_loops,
                dropped_duplicates: parsed.duplicates,
            },
        })
    }
}
```

### Task 7: `bench gen snap`

`bench gen snap` is the imperative path to the SNAP generator, beside `bench gen watdiv` and `bench gen lubm`. It takes `--graph <com-amazon|com-dblp|com-youtube>` or `--url URL --sha256 HEX`, an optional `--queries`, and the shared output flags `--tag` (required) and `--output-dir` through `GenTarget`, which this task adds (first lander; the struct and `prepare` are copied byte for byte from the H2O spec's § Surface, and H2O's push 2 drops its own copy at merge). /// The name of a `bench gen snap` benchmark: `snap-<name>-<tag>`, where
```rust
/// `<name>` is the graph's name or the URL's file name up to its first `.`
/// (`.../com-orkut.ungraph.txt.gz` gives `com-orkut`).
///
/// A URL with no such name (one ending in `/`, or in `/.gz`) is an error that
/// names it. Whether the result is a portable filename is not checked here:
/// `BenchmarkDefinition::validate` does that for the finished name.
fn snap_bench_name(
    graph: Option<kermit_bench::SnapGraph>, url: Option<&str>, tag: &str,
) -> anyhow::Result<String> {
    let name = match (graph, url) {
        | (Some(g), _) => g.name(),
        | (None, Some(u)) => {
            let Some(stem) = kermit_generate::snap::url_stem(u) else {
                anyhow::bail!("--url {u:?} has no file name to name the benchmark by");
            };
            stem
        },
        | (None, None) => anyhow::bail!("pass --graph, or --url together with --sha256"),
    };
    Ok(format!("snap-{name}-{tag}"))
}

/// Handler for `bench gen snap`: download (or take) a SNAP edge list and write
/// a benchmark from it through [`kermit_generate::snap::SnapGenerator`].
///
/// The benchmark is named by [`snap_bench_name`]. The name, the digest and
/// the URL are checked once, by validating the equivalent declarative spec,
/// before anything is downloaded. The run has no `spec_hash`, like every
/// imperative `bench gen`.
fn run_gen_snap(
    graph: Option<SnapGraphArg>, url: Option<String>, sha256: Option<String>,
    queries: Vec<SnapQueryArg>, target: GenTarget,
) -> anyhow::Result<()> {
    use {
        kermit_bench::{GeneratorSpec, SnapGraph, SnapQuery},
        kermit_generate::snap::{SnapGenerator, SnapSource},
    };

    let graph = graph.map(SnapGraph::from);
    let queries: Vec<SnapQuery> = queries.into_iter().map(SnapQuery::from).collect();
    let queries = (!queries.is_empty()).then_some(queries);
    let spec = GeneratorSpec::Snap {
        graph,
        url: url.clone(),
        sha256: sha256.clone(),
        queries: queries.clone(),
    };

    let bench_name = snap_bench_name(graph, url.as_deref(), &target.tag)?;

    BenchmarkDefinition {
        name: bench_name.clone(),
        description: String::new(),
        relations: vec![],
        queries: vec![],
        generator: Some(spec),
    }
    .validate()?;

    let source = match (graph, url, sha256) {
        | (Some(g), None, None) => SnapSource::named(g),
        | (None, Some(url), Some(sha256)) => SnapSource::Remote { url, sha256 },
        | _ => anyhow::bail!("pass --graph, or --url together with --sha256"),
    };
    let out = target.prepare("snap", &bench_name)?;
    let generator = SnapGenerator::new(
        kermit_rdf::generator::Target {
            out_dir: &out,
            bench_name: &bench_name,
            tag: &target.tag,
            spec_hash: None,
        },
        graph,
        source,
        queries.as_deref(),
    );
    kermit_generate::run(&generator)?;
    eprintln!("snap benchmark written to {}", out.display());
    Ok(())
}
```

```rust
/// Loads the generated `edge` relation as `R` into a fresh engine planned by
/// `planner`, runs every query through `JA`'s entry points (building the
/// reordered copies it reads under `--column-orders any`), and returns one
/// line per query whose result count differs from its `expected`. A join
/// that errors panics, naming the cell: under `stored` that is the
/// `CyclicAttributeOrder` check, which `cycle4` as written must not trip.
fn cell_mismatches<R, JA>(
    bench: &BenchmarkDefinition, dir: &Path, planner: &Planner, label: &str,
) -> Vec<String>
where
    R: Relation + Cardinality,
    JA: JoinEntry<R>,
{
    let (relations, inputs) =
        load_parquet_relations::<R>(dir, bench.relations.iter().map(|r| r.name.as_str()));
    let mut database = JA::database(relations, planner.required_statistics());

    let mut mismatches = Vec::new();
    for q in &bench.queries {
        let want = q.expected.expect("every SNAP query carries expected");
        let parsed: JoinQuery = q.query.parse().expect("datalog parse failure");
        let (rows, _) = join_under_planner::<R, JA>(&mut database, &inputs, parsed, planner)
            .unwrap_or_else(|e| {
                panic!("[{label}] {} / {}: {e}", std::any::type_name::<R>(), q.name)
            });
        let got = rows.len() as u64;
        if got != want {
            mismatches.push(format!(
                "  [{label}] {} / {}: got {got}, expected {want}\n    query: {}",
                std::any::type_name::<R>(),
                q.name,
                q.query
            ));
        }
    }
    mismatches
}

    let mut want: Vec<Vec<usize>> = Vec::new();

        let d: usize = fields.next().unwrap().parse().unwrap();

        if s != d && seen.insert((s.min(d), s.max(d))) {
            want.push(vec![s, d]);
            want.push(vec![d, s]);
        }
    }
    let (_, tuples) = read_parquet(&parquet).expect("edge.parquet reads back");
    assert_eq!(tuples.to_vecs(), want);
}
```

```rust
//! CLI end-to-end for SNAP (#96): `bench gen snap --url … --sha256 …` and the
//! declarative `kind: snap` YAML, against a loopback HTTP server that serves
//! the gzipped mini fixture. No network is used.
//!
//! `XDG_CACHE_HOME` and `KERMIT_WORKSPACE` point at temp dirs, so the shared
//! cache and the real `benchmarks/` are never touched. Linux only, as the
//! other CLI tests that set `XDG_CACHE_HOME`.
//!
//! The server counts the connections it accepts, one per download, so the
//! tests can tell a cache hit (no download) from a regeneration (one more).

use {
    flate2::{write::GzEncoder, Compression},
    kermit_bench::{cache::sha256_hex, BenchmarkDefinition},
    std::{
        collections::BTreeSet,
        fs,
        io::{Read, Write},
        net::{TcpListener, TcpStream},
        path::{Path, PathBuf},
        process::{Command, Output},
        sync::{
            atomic::{AtomicUsize, Ordering},
            Arc,
        },
    },
    tempfile::{NamedTempFile, TempDir},
};

/// The fixture's counts, in `SnapQuery::ALL` order; see `snap_generate.rs`
/// for their independent derivation.

    ("triangle", 36),
    ("path3", 482),
    ("cycle4", 322),
    ("clique4", 24),
];

fn kermit_bin() -> PathBuf { PathBuf::from(env!("CARGO_BIN_EXE_kermit")) }

fn skip_unsupported() -> bool {

        eprintln!("skipping cli_snap_gen test: XDG_CACHE_HOME needs Linux");

/// Gzips `text` in memory (no timestamp, so the bytes depend only on it).
fn gzip(text: &str) -> Vec<u8> {
    let mut encoder = GzEncoder::new(Vec::new(), Compression::default());
    encoder.write_all(text.as_bytes()).expect("gzip the fixture");
    encoder.finish().expect("finish the gzip stream")
}

/// A loopback HTTP server that answers every connection with the same body.
struct Server {
    url: String,
    connections: Arc<AtomicUsize>,
}

impl Server {
    /// Binds a loopback port and serves `body` to any number of connections
    /// from detached threads that end with the test process.
    fn start(body: Vec<u8>) -> Self {
        let listener = TcpListener::bind("127.0.0.1:0").unwrap();
        let url = format!(
            "http://{}/mini.ungraph.txt.gz",
            listener.local_addr().unwrap()
        );
        let connections = Arc::new(AtomicUsize::new(0));
        let counter = Arc::clone(&connections);
        let body: Arc<[u8]> = body.into();
        std::thread::spawn(move || {
            for stream in listener.incoming().flatten() {
                counter.fetch_add(1, Ordering::SeqCst);
                let body = Arc::clone(&body);
                std::thread::spawn(move || respond(stream, &body));
            }
        });
        Self { url, connections }
    }

    /// Connections accepted so far: the number of downloads.
    fn connections(&self) -> usize { self.connections.load(Ordering::SeqCst) }
}

/// Reads one request head, then answers `200 OK` with `body` and closes.
fn respond(mut stream: TcpStream, body: &[u8]) {
    let mut request = Vec::new();
    let mut buf = [0u8; 1024];
    while !request.windows(4).any(|w| w == b"\r\n\r\n") {
        match stream.read(&mut buf) {
            | Ok(0) | Err(_) => return,
            | Ok(n) => request.extend_from_slice(&buf[..n]),
        }
    }
    let head = format!(
        "HTTP/1.1 200 OK\r\nContent-Length: {}\r\nConnection: close\r\n\r\n",
        body.len()
    );
    let _ = stream.write_all(head.as_bytes());
    let _ = stream.write_all(body);
}

/// Three temp dirs: the cache root, the workspace and scratch space.
struct Sandbox {
    cache: TempDir,
    workspace: TempDir,
    work: TempDir,
}

impl Sandbox {
    fn new() -> Self {
        let sandbox = Self {
            cache: tempfile::tempdir().unwrap(),
            workspace: tempfile::tempdir().unwrap(),
            work: tempfile::tempdir().unwrap(),
        };
        fs::create_dir_all(sandbox.workspace.path().join("benchmarks")).unwrap();
        sandbox
    }

    /// `<cache>/kermit/benchmarks/<name>`, where the binary keeps a benchmark.
    fn cache_subdir(&self, name: &str) -> PathBuf {
        self.cache.path().join("kermit/benchmarks").join(name)
    }

    /// A `kermit` command inside the sandbox.
    fn kermit(&self) -> Command {
        let mut command = Command::new(kermit_bin());
        command
            .env("XDG_CACHE_HOME", self.cache.path())
            .env("KERMIT_WORKSPACE", self.workspace.path())
            // Reach the loopback server directly, whatever proxy the host sets.
            .env("NO_PROXY", "127.0.0.1")
            .env("no_proxy", "127.0.0.1");
        command
    }

    /// Serves the gzipped fixture and returns the server with the digest of
    /// the bytes it serves.
    fn serve_mini(&self) -> (Server, String) {
        let gz = self.work.path().join("mini.ungraph.txt.gz");
        fs::write(&gz, gzip(&fixture_text())).unwrap();
        let sha256 = sha256_hex(&gz).unwrap();
        (Server::start(fs::read(&gz).unwrap()), sha256)
    }

    /// `bench gen snap --url <url> --sha256 <sha256> --tag t`.
    fn gen_snap(&self, url: &str, sha256: &str) -> Output {
        self.kermit()
            .args(["bench", "gen", "snap", "--url", url, "--sha256", sha256])
            .args(["--tag", "t"])
            .output()
            .unwrap()
    }

    /// `bench run <name> <cell…> --metrics iteration <extra…>` with the
    /// fastest Criterion settings, returning the output and the JSON report
    /// (empty when the run wrote none).
    fn bench_run(
        &self, name: &str, cell: &[&str], extra: &[&str],
    ) -> (Output, Vec<serde_json::Value>) {
        let report = NamedTempFile::new_in(self.work.path()).unwrap();
        let output = self
            .kermit()
            .args([
                "bench",
                "--sample-size",
                "10",
                "--measurement-time",
                "1",
                "--warm-up-time",
                "1",
            ])
            .arg("--report-json")
            .arg(report.path())
            .args(["run", name])
            .args(cell)
            .args(["--metrics", "iteration"])
            .args(extra)
            .output()
            .unwrap();
        let text = fs::read_to_string(report.path()).unwrap();
        let reports = if text.trim().is_empty() {
            vec![]
        } else {
            serde_json::from_str(&text).unwrap()
        };
        (output, reports)
    }

    /// Writes the workspace YAML `benchmarks/snap-mini.yml`: a `kind: snap`
    /// generator over `url` with the given `queries` list body.
    fn write_spec(&self, url: &str, sha256: &str, queries: &str) {
        let yaml = format!(
            "name: snap-mini\n\
             description: declarative SNAP smoke test\n\
             generator:\n  \
               kind: snap\n  \
               url: {url}\n  \
               sha256: {sha256}\n  \
               queries: [{queries}]\n"
        );
        fs::write(self.workspace.path().join("benchmarks/snap-mini.yml"), yaml).unwrap();
    }
}

}

/// The names in `dir`, sorted; empty when it does not exist.

    names.sort();
    names
}

        fs::read_to_string(cache.join("meta.json")).unwrap(),
        meta_text,
        "a hit must not regenerate"
    );
```

````markdown
SNAP is Stanford's collection of real network datasets. Its "com-" graphs, introduced
by Yang and Leskovec (2012), are large undirected social and product networks
published with ground-truth communities: Amazon co-purchases, DBLP co-authorship and

## Inference / preprocessing

SNAP files are edge lists: `#` comment lines, then one `s d` pair per line, separated
by a tab or spaces. The parser keeps the raw ids (keys are `usize` already, so there is
no dictionary and no remapping; amazon has 334,863 nodes but ids up to 548,551).

| Rule | Effect | Recorded |
|------|--------|----------|
| Line starts with `#` | Skipped | — |
| Self-loop (`s = d`) | Dropped | `dropped_self_loops` |
| Unordered pair seen before (a reversed repeat included) | Dropped; the first occurrence is kept | `dropped_duplicates` |
| Each kept line `(s, d)` | Becomes rows `(s, d)` then `(d, s)`, in file order | `relations[0].rows` |
| Not exactly two unsigned integers (a blank line included) | Error: `<source>:<line>: malformed edge line …`, with the 1-based line number, comments counted | — |
| No line survives | Error: `<source> has no edges after dropping <n> self-loops and <m> duplicates` | — |

Dropping self-loops and duplicates makes set and bag counts agree, so HashTrie's
multiset count matches the sorted tries'. A malformed line is an error, never skipped.
An edgeless input is an error because a benchmark with no data measures nothing. This
only matters for a `url`: all three named graphs have exactly four header lines, no
malformed line, no self-loop and no duplicate, and every data line has `s < d`.

### The queries

The relation is `edge(src, dst)`, symmetric: every undirected edge is stored in both
directions. No query forces its variables to be distinct, so the queries count
**walks**, not simple paths or simple cycles.

| Name | Datalog | Counts |
|------|---------|--------|
| `triangle` | `T(A, B, C) :- edge(A, B), edge(B, C), edge(A, C).` | 6 × triangles |
| `path3` | `P(A, B, C, D) :- edge(A, B), edge(B, C), edge(C, D).` | 3-step walks, 1ᵀA³1; vertices may repeat (A = C is allowed) |
| `cycle4` | `C(A, B, C, D) :- edge(A, B), edge(B, C), edge(C, D), edge(A, D).` | closed 4-step walks, tr(A⁴); **not** 8 × 4-cycles |
| `clique4` | `K(A, B, C, D) :- edge(A, B), edge(A, C), edge(A, D), edge(B, C), edge(B, D), edge(C, D).` | 24 × 4-cliques |

- **`triangle` and `clique4`** relate every pair of their variables by an edge, and
  `edge` has no self-loops, so their variables are always distinct. They count true
  triangles and 4-cliques, once per ordering of the vertices (3! and 4!).
- **`path3` and `cycle4`** relate only adjacent variables, so non-adjacent ones may
  coincide. A walk that doubles back (`A = C` or `B = D`) is a row. Such walks are 62%
  of amazon's `cycle4` count and 16.8% of dblp's, so `cycle4`'s count is far from
  eight times the number of 4-cycles.
- **Why `cycle4` is written `edge(A, D)`.** The natural last atom is `edge(D, A)`, but
  under `--column-orders stored` (the default) every atom's variables must follow its
  stored column order, and `edge(A, B)`, `edge(B, C)`, `edge(C, D)` already force
  A before B before C before D, so `edge(D, A)` is `CyclicAttributeOrder`. The relation
  is symmetric, so `edge(A, D)` holds the same tuples and the same answers, and the
  query plans without a reordered copy. Write your own cycle queries the same way.

|---|---|---|---|---|
| `com-amazon` | 4,002,774 | 206,831,062 | 65,863,072 | 6,623,064 |
| `com-dblp` | 13,346,310 | 1,453,845,122 | 530,084,528 | 401,116,608 |

That is 667,129 triangles and 275,961 4-cliques in amazon, and 2,224,385 triangles and
16,713,192 4-cliques in dblp. `com-youtube`'s counts are not pinned.

### How `expected` is computed

Every query's `expected` comes from `kermit-generate/src/snap/counts.rs`, which reads
only the parsed rows. It shares no code with the joins, so a bug in a trie, an
intersection routine or an optimiser cannot make the count wrong in the same way.

- **`path3`**: the sum over rows (b, c) of d(b) · d(c).
- **`triangle`, `clique4`**: edges are oriented from the lower to the higher
  (degree, id), so each triangle or 4-clique is counted once; the oriented neighbour
  lists are intersected, then the count is scaled by 6 or 24.
- **`cycle4`**: tr(A⁴), the sum over v and w of (A²)[v][w] squared, tallying the 2-step walks
  from each v.
- All arithmetic is checked `u64`: an overflow is an error, never a wrong `expected`.

`bench run snap-amazon -i all -a all --verify` then runs each query once and aborts on a
mismatch. `clique4`, with six atoms and four levels, checks deep leapfrog descents on real data,
which the small fixtures of the join test suites cannot.

## Determinism

The `.gz` is pinned by its digest, and parsing is a pure function of it: the same file
always gives the same rows in the same order and the same counts. The Parquet bytes are
identical when regenerating with the same build; they can differ across builds, since
the file's footer records the Parquet writer's version. `meta.json` records the `.gz`
SHA-256, each relation's SHA-256 and the rows dropped, so a cache can be identified
after the fact.

## Practical scale ceiling

Result sizes are the cost, not the data, which is at most 6 million rows. The joins
stream every answer to a counter and never collect, but timing them still enumerates
every row:

| Graph | `triangle` | `path3` | `cycle4` | `clique4` |
|---|---|---|---|---|
| `com-amazon` | 4.0 M | 207 M | 66 M | 6.6 M |
| `com-dblp` | 13.3 M | **1.45 billion** | 530 M | 401 M |
| `com-youtube` | not pinned | billions | billions | not pinned |

- **`com-youtube` is generated on request and not committed.** `bench gen snap --graph
  com-youtube` works (its Σ d(v)² is 2.96 × 10⁹), but a `path3` or `cycle4` run on it
  is far beyond the other two; use `--queries triangle,clique4` for a lighter run.
- **Never write a result to disk.** `kermit join` writes every row as CSV; on dblp's
  `path3` that is 1.45 billion rows. `bench run` only counts.
- **The oracle** runs in seconds for amazon and dblp and about ten seconds for youtube
  (`cycle4`, the dearest), over all rows in memory (youtube: about 96 MB). **The
  parser** also keeps a set of the unordered pairs it has seen (about 100 MB at
  youtube) to drop duplicates.
- **Downloads** are 4.5 MB, 4.1 MB and 10.6 MB. A download that stalls for 30 s fails;
  there is no total time limit.

## Vendored generator

Nothing is vendored: SNAP publishes plain gzipped edge lists, and kermit parses them
itself (`kermit-generate/src/snap.rs`).

| Field | Value |

| Source URL | `https://snap.stanford.edu/data/bigdata/communities/com-<name>.ungraph.txt.gz` |
| Version pin | the `.gz` SHA-256 per graph (§ Workload reference); SNAP's files carry no version or tag |
| Build toolchain | none (no external tool runs) |
| Vendor path | none |
| Committed vs fetched | nothing committed; the `.gz` is downloaded on generation and kept in `raw/` of the benchmark's cache directory |
````

### From `T1-T5.md`

The fragments the tests assert are my wording: `not both`, `needs \`graph\` or \`url\``, `only for \`url\``, `requires \`sha256\``, `http:// or https://`, `64 lowercase hex`, `non-empty`, `listed twice`.
